# WANTED: ME — CASE #001

**존재하지 않는 네 명의 용의자.** 서로 다른 네 기록을 추적하며 한 사람의 삶과 선택을 복원하는 한국어 심리 스릴러 수사 게임입니다.

## 바로 플레이

빌드 결과물의 **`dist/PLAY.html`을 더블클릭**하세요. JS·CSS가 포함된 오프라인 진입점이며 이미지도 프로젝트 안에 들어 있습니다. `dist` 폴더 전체를 함께 보관해야 합니다. 인터넷, 로그인, 결제, API 키, 백엔드는 필요하지 않습니다. 브라우저에 따라 `file://` 저장을 제한할 수 있지만 저장을 쓸 수 없어도 현재 창에서 플레이할 수 있습니다.

일반적인 개발과 정적 배포에는 아래 명령을 사용합니다. Node.js 22 이상 및 pnpm이 필요합니다.

```sh
pnpm install
pnpm dev
```

터미널에 표시된 로컬 주소를 여세요. 기본 주소는 `http://127.0.0.1:5173`입니다.

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm build`는 사진 슬롯 검사 → TypeScript 검사 → Vite 빌드 → 오프라인 PLAY.html 생성을 수행합니다. `dist/index.html`은 정적 호스팅용 진입점입니다. `dist/PLAY.html`은 파일로 열기 위한 별도 진입점입니다.

## 게임 흐름

1. 프롤로그 — 신원 충돌 접수, 네 개의 기록 발견
2. 가벼운 흔적들 — 여덟 개의 자료를 일상·직업·불명으로 분류
3. 출생과 이동 — 방콕에서 한국, 현재 생활권까지 순서 복원
4. 연구소의 의문 — 감피 탄닌 공동연구의 동기·목표·과정·한계 매칭
5. 사라진 시기 — 일곱 시기의 타임라인 복원 후 네 기록을 같은 토큰에 직접 연결
6. 진짜 미스터리 — 추정을 배제하고 진로 전환의 실제 근거 다섯 개 선별
7. 최종 챕터 — 변하지 않은 가치관을 선택하고 이름과 현재 신원 공개

오답에 패널티는 없습니다. 힌트는 방향 안내와 구체적인 안내 두 단계입니다. 챕터를 완료하면 수사 보드의 증거와 붉은 실이 늘어납니다. 게임 세계관의 신원 오류와 감시 경고는 **허구**이며 실제 감시·추적·서버 전송 기능이 없습니다.

## 4분 30초 발표

상단의 **발표 모드**를 켜세요. 하단 제어판에서 타이머 일시정지, 빠른 이동, 현재 챕터 재시작, 힌트, 풀이 건너뛰기, 다음 챕터를 사용할 수 있습니다. 타이머는 이 페이지를 연 세션에서만 동작하며 초기화하면 00:00으로 돌아갑니다. 4분 30초가 지나도 자동으로 화면을 넘기거나 플레이를 막지 않습니다.

권장 퍼즐 진행 시간 합계는 3분 50초입니다. 나머지 40초를 오프닝과 엔딩에 사용하세요. 발표 전 설정의 **모든 수사 기록 초기화**로 깨끗하게 시작할 수 있습니다. 빠른 이동은 이전 챕터 증거를 자동 복원합니다. 일반 모드에서는 이전 챕터를 완료해야 다음 챕터가 열립니다.

## 조작과 접근성

- 마우스: 카드 클릭 → 분류 항목 클릭. 드래그 앤 드롭도 지원합니다.
- 순서 복원: 기록을 클릭해 추가하고 위·아래 화살표로 재정렬하거나 제거합니다.
- 키보드: Tab으로 이동하고 Enter/Space로 선택합니다. Esc는 창을 닫습니다. 대화상자에서 포커스를 유지하고 닫으면 이전 요소로 돌아갑니다.
- 모바일: 세로 레이아웃과 클릭 기반 조작을 사용하며 가로 드래그가 필수인 퍼즐은 없습니다.
- 시스템의 `prefers-reduced-motion`을 따르면 스캔·도장·전환 애니메이션을 생략합니다.
- 배경음 및 효과음은 Web Audio로 합성합니다. 첫 조작 전에는 재생하지 않으며 별도 음원 다운로드는 없습니다. 기본 볼륨은 각각 30%입니다. 설정에서 BGM/SFX를 따로 조절하세요.

## 개인 사진 및 레퍼런스 교체

아래 위치에 파일을 넣은 뒤 **`pnpm dev`를 다시 시작하거나 `pnpm build`로 재빌드**하면 자동으로 감지합니다. 파일이 없으면 네 장면 이미지나 CSS 실루엣으로 대체합니다. 얼굴 없는 커플 사진은 엔딩 뒤 보너스 기록에만 나타납니다.

```text
public/assets/people/portrait-main.jpg
public/assets/people/couple-1.jpg
public/assets/people/couple-2.jpg
public/assets/memories/piano.jpg
public/assets/memories/friends.jpg
public/assets/memories/research.jpg
public/assets/memories/polestar.jpg
public/assets/reference/scene-01-board.jpg
public/assets/reference/scene-02-airport.jpg
public/assets/reference/scene-03-lab.jpg
public/assets/reference/scene-04-airforce.jpg
public/assets/reference/scene-05-devroom.jpg
public/assets/reference/scene-06-boardcloseup.jpg
public/assets/reference/scene-07-table.jpg
```

주소·번호판·군 신분 정보·연인의 실명이 드러나는 사진은 넣지 마세요. 개인 사진 슬롯은 본인이 선택해서 추가하는 용도입니다.

현재 제공된 원본 레퍼런스 7장 및 연구 보고서 원문은 없습니다. 개발요청서의 묘사를 바탕으로 수사 보드·책상 질감을 CSS로 만들었으며 네 시기의 익명 장면은 AI로 생성했습니다. 생성 장면은 실제 개인 사진이나 역사적 증거가 아닙니다. 연구 자료는 감피 탄닌 소독제를 제조·평가하려는 시도와 시행착오·평가 한계만 반영합니다. 상용화·수상·완전한 입증을 주장하지 않습니다.

`scene-06-boardcloseup.jpg`와 `scene-07-table.jpg`는 선택적으로 증거 보관함·퍼즐 책상 배경에 적용됩니다. 기본 화면에서는 코르크·서류·붉은 실·조사 테이블의 기능을 CSS로 재현합니다.

## 정적 배포

`pnpm build` 뒤 **`dist` 전체**를 정적 호스팅에 업로드하세요. 사이트는 별도 API나 서버 데이터베이스를 사용하지 않습니다. Vite의 상대 경로 설정으로 하위 경로 배포도 지원합니다. 사용자별 진행은 해당 브라우저에만 남습니다. `.openai/hosting.json`은 현재 Sites 프로젝트의 정적 출력 위치를 선언합니다.

## 검증

`pnpm test`는 순서·매칭·사실 선별·저장 복구 검증과 React 컴포넌트 상호작용 검증을 실행합니다. 컴포넌트 검증은 실제 브라우저나 네트워크를 사용하지 않습니다. 자동 브라우저 접근은 이 작업의 보안 승인에서 거절되어, 실제 화면·모바일 렌더링·브라우저 오디오 청취 검증은 완료하지 못했습니다.

## 기술

React 19 · TypeScript · Vite 6 · Tailwind CSS 4 · Lucide 아이콘. 상태 관리와 애니메이션은 React/CSS를 사용합니다. 개인 사진·로그인·서버 없이 시작부터 엔딩까지 플레이할 수 있습니다.
